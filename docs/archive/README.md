# Historical Project Records

This directory contains completed, superseded, or time-bound progress logs, plans, and handoffs.
They are retained for traceability and must not be treated as active instructions.

The only live status dashboard is [`docs/PROGRESS_CONTEXT.md`](../PROGRESS_CONTEXT.md). A new plan
becomes active only when that dashboard names it and the owner approves its scope.

- `progress/` — superseded dashboard snapshots
- `plans/` — completed or abandoned implementation plans
- `handoffs/` — superseded workstream handoff logs
